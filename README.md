# DSH Game Hub：本地棋牌与 DSH 对弈实验

这是一个面向本机运行的棋牌小游戏项目。当前已实现五子棋：浏览器负责显示棋盘与记录，服务端负责规则、座位权限、棋局状态和持久化；DSH 可按选定模式参与，本地算法负责普通托管与兜底。项目起点是验证“AI 伴侣怎样才算亲自参与游戏”，同时减少无意义的模型调用，并让真实执行来源可追溯。

## 当前功能

- 15×15 自由五子棋，不启用 Renju 禁手；每局随机分配黑白和先手。
- 浏览器支持真人对局、本地引擎对局，以及独立只读观战视图。
- 三种 DSH 决策方式：纯本体、纯下棋鱼、本体+下棋鱼；另有纯本地引擎模式。
- 混合模式由本地评分器决定何时唤醒 DSH；普通走子交给本地引擎。引擎推荐点不会限制 DSH 的合法落点。
- 对局记录默认收起；展开后可查看走子来源、各方手数和思考时间统计。
- 页面只统计本局游戏模型用量，可展开查看请求步骤、缓存命中/未命中等明细；不把 QQ 普通聊天计入游戏统计。
- 支持主动结束对局并请求桥接通知归档。另有可重复运行的奖励测试邀请入口；测试邀请不占每日自动邀请次数，但测试对局结束时间会参与自动邀请冷却。
- 桥接投递到同一 DSH 会话的提示按队列顺序处理；游戏提示不会作为后台轮询任务。

## 环境要求

- Windows 10/11
- Node.js 24 或更高版本
- pnpm 11.25 或兼容版本
- 若要接入 DSH：需另行安装并运行 DSH 与 QQ Bridge。它们不包含在本仓库内。

## 安装与启动

1. 下载或克隆本仓库，将项目放在一个独立目录。
2. 安装 Node.js 24+ 和 pnpm 11.25+，在 PowerShell 中运行 `node --version`、`pnpm --version` 确认版本。
3. 在项目根目录复制 `.env.example` 为 `.env`。仅填写本机桥接地址和自行生成的本机随机密钥；不要把真实密钥提交到 GitHub。
4. 如果只运行五子棋和本地引擎，不需要配置模型 API 密钥。若要接入 DSH/桥接，按你自己的 DSH 与桥接安装说明配置桥接侧；本仓库不会替你安装或配置 DSH。
5. 在项目根目录双击 `一键运行游戏.bat`。也可以在 PowerShell 运行 `pnpm install`，再运行 `pnpm start`。
6. 浏览器打开 `http://127.0.0.1:8787`。停止服务时关闭 Game Hub 的命令窗口。
7. 要验证奖励邀请流程，先确认 DSH、QQ Bridge 和 Game Hub 的本机环境变量已正确配置，再双击 `游戏邀请测试.bat`。此入口会实际向本机桥接提交邀请；它不计每日自动邀请次数，但会影响自动邀请冷却。

## 决策模式

- **纯本体**：轮到小鲸鱼时由 QQ 主会话完成决策。
- **纯下棋鱼**：由独立的棋局会话按本体提供的思路执行。
- **本体+下棋鱼**：本体开局提供思路并亲自落子；随后下棋鱼执行，评分器判断需要关键决策时交回本体。
- **本地引擎**：不请求大模型，由本地算法完成对局。

界面和逐手记录会根据实际执行来源标记 DSH、本体、下棋鱼、托管或引擎兜底。

## 本地数据与安全

棋局 SQLite 数据、日志、`.env` 和桥接/DSH 状态属于本机运行数据，不应提交到公共仓库。桥接密钥仅用于本机服务之间的鉴权，不应写入提示词、聊天记录或公开文件。公开发行包只提供 `.env.example` 模板。

## 项目设计记录

- `docs/DECISION_MODE_PLAN.md` 记录当前决策接入的方案 A 与备用方案 B。
- `docs/DUAL_LAYER_CHESS_PLAN.md` 记录双层五子棋协作、思路卡、牵引绳、触发器和自动邀请的实施约定。
- `docs/DECISION_NOTES.md` 保留设计参与者对“亲自参与”、节省调用和保持陪伴感的原始反思。它是项目设计背景的一部分，不等同于接口规格。
- `PROJECT_PLAN.md` 是更大棋牌项目的总体计划；其他游戏尚未在当前版本实现。

## 后续方向

计划逐步增加中国象棋、斗地主和四川麻将，并支持三种参与方式：纯本体、纯下棋鱼、本体与下棋鱼共同出战。每种新游戏按独立阶段实现规则、信息权限、本地对手、决策接入和验证，先验证完整闭环再扩展。
